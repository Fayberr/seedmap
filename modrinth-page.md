## description
Seed-based world map with structures, biome search and waypoint navigation inside Minecraft.

## body
SeedMap opens a world map in-game and predicts unexplored regions from the world seed.

- Overworld, Nether and End maps.
- Find biomes, structures and geodes.
- Filter structure markers and show slime chunks or chunk boundaries.
- Set waypoints and navigate with a HUD arrow or beam.
- Export the current map view to PNG.

Client-side Fabric mod for Minecraft 26.3. Requires Fabric API. Enter the world seed manually on multiplayer servers.
